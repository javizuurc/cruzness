# Design Taste Frontend

Wrapper para dirección artística, uso de fotografías reales y comprobación
en un navegador real; no incluye el contenido externo completo.

- Origen: [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)
- Página: [tasteskill.dev](https://tasteskill.dev)
- Licencia: MIT (Copyright (c) 2026 Leonxlnx)
- Requisitos: Node 22+ y Chrome, Edge o Chromium.

## Instalación

```sh
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

## Cuándo usarla

Al crear landing pages, portfolios, webs premium y experiencias visuales
originales; establece dirección artística, prefiere fotos reales pertinentes
y valida el resultado en navegador real (vía MCP `playwright` del paquete).

## Convenciones (obligatorio)

- Trabaja en el sistema del proyecto destino (su styling, sus componentes,
  su i18n); no introduzcas un segundo sistema solo para aplicar un cambio.
- Usa HTML semántico (`header`, `main`, `section`, `article`, etc.).
