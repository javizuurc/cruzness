# Frontend Design

Wrapper para orientar decisiones estéticas deliberadas antes de codificar y
evitar patrones visuales genéricos de IA. No incluye el contenido externo
completo.

- Origen: [anthropics/skills — frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)
- Licencia: Apache-2.0

## Instalación

```sh
npx skills add https://github.com/anthropics/skills --skill frontend-design
```

## Cuándo usarla

Antes de crear o renovar landing pages, portfolios, webs premium y
experiencias visuales originales; define una dirección estética intencional
antes de implementar.

## Convenciones (obligatorio)

- Trabaja en el sistema del proyecto destino (su styling, sus componentes,
  su i18n); no introduzcas un segundo sistema solo para aplicar un cambio.
- Usa HTML semántico (`header`, `main`, `section`, `article`, etc.).
